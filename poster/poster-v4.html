THE BREAKTHROUGH
To our knowledge, the first framework to combine physics-informed learning, calibrated RUL distributions and GPU-scale particle inference — the four capabilities every prior approach leaves incomplete — validated on real NASA PCoE cells across 40 measured configurations on two machines.

01Research gap — what no one has combined

Battery RUL research has four mature ingredients. No published framework combines them — a maintenance decision needs all four at once.

Verified against a systematic review of 33 works: the closest LSTM+filter hybrid [28] explicitly lists our physics constraints as future work; CUDA particle filters [17] never touched battery data. P3-EVHM closes all four cells — that closure is the contribution.

03Method — the physics enters the loss

(4) L = MSE(q̂, q) + λ1 · mean ReLU(q̂t − qt) + λ2 · mean(Δq̂t − g(Tt))²
(5) g(T) = clamp(Â · (T − T̄), min = 0)  —  prior fitted from training cycles, not a hard clamp
(6) qi(k) = qi(k−1) − di + εk,   wi ∝ exp(−(qobs − qi)² / 2σ²)
(8) RUL = median { k : qi(k) ≤ qEOL },   report [P2.5, P97.5]

A 1–32 LSTM over a W = 8 window; identical seeds and metrics for baselines B1–B6, so the comparison is the physics, not the tuning. Same code runs on CPU or CUDA (device="auto").

04System — five agents, one framework

A3 and A4 run on the GPU; the same code runs on CPU for parity. Four doors into one engine: Python API, CLI, dashboard, Kaggle kernel.

05Evidence for C1 — the physics loss works

Violation rate V per configuration (share of predicted steps where capacity rises — physically impossible). All 20 configurations improve or tie; the two catastrophes (V = 1.0, configs 04/08) are eliminated entirely.

07Evidence for C3 — GPU scaling

Honest crossover reported: below ~5k particles the warm CPU wins (0.65×); the GPU pays exactly where prognostics needs it — large clouds, sharp intervals, real time.

08Conclusions & future work

Conclusions. The fusion is the contribution: physics constraints make LSTM prognostics physically consistent at no accuracy cost; the particle filter turns that forecast into a calibrated maintenance decision in every configuration tested; GPU-scale inference makes the cloud size that sharp intervals need affordable. Open-sourced end to end, with 40 measured configurations as evidence.

Future work. Pack-level validation beyond single cells; prior-floor tuning for early-start predictions (40% of life); interval coverage toward 0.95; streaming on-vehicle deployment.
